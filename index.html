Dépôt apt d'OcMintux

Les PC OcMintux reçoivent les mises à jour d'ici tout seuls. Pour un Linux Mint 22 :

sudo curl -fsSL https://gms64260.github.io/ocmintux/ocmintux.gpg -o /usr/share/keyrings/ocmintux.gpg
sudo curl -fsSL https://gms64260.github.io/ocmintux/ocmintux.sources -o /etc/apt/sources.list.d/ocmintux.sources
sudo apt update && sudo apt install ocmintux
