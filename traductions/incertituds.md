# Formes à faire relire

Textes nouveaux d'OcMintux (ceux repris d'Occitux y ont déjà été vérifiés :
`demarrage.essayer`, `installer`, `installer_auto`, `memoire`,
`avertissement_auto`, `fin.*`).

| Clé | Forme | Doute |
|---|---|---|
| `demarrage.micrologiciel` | micrologicial / micrologiciau | Calque de « micrologiciel » sur *logicial / logiciau* (glossaire d'Occitux) ; non attesté. *Firmware* se dit aussi « micrologicial » dans les catalogues GNOME occitans ? À vérifier. |
| `demarrage.volume_suivant` | Aviar sul disc seguent / sus lo disc seguent | « Démarrer » rendu par *aviar* comme dans Occitux (« Reaviar ») ; *sul* (languedocien) et *sus lo* (béarnais). |
| `demarrage.oem` | Installacion pels fabricants / entaus fabricants | *fabricant* : forme courante, non vérifiée dans le corpus. |
| `demarrage.materiel` | Deteccion del material / deu material | *material* pour « matériel informatique » : à confirmer. |
| `compte.enseignants` | Regent | Mot des Calandretas pour l'enseignant (attesté en gascon, glossaire d'Occitux) ; féminin *regenta* : le nom affiché peut être changé dans « Comptes ». |
